# 📊 Sales Data Analysis using SQL & Power BI

## 📌 Project Overview

This project focuses on analyzing sales data using **PostgreSQL and Power BI** to generate meaningful business insights.

SQL was used to query, clean, filter, and analyze sales records, while Power BI was used to create an interactive dashboard to visualize sales performance across different regions, cities, products, and sales channels.

## 🛠️ Tools & Technologies

- **PostgreSQL** – Database management and SQL analysis
- **Power BI** – Interactive dashboard and data visualization
- **SQL** – Data querying and business analysis

## 📂 Dataset Information

The dataset contains sales transaction details with the following columns:

- Order_Date
- Order_ID
- City
- Region
- Category
- Product
- Sales_Channel
- Quantity
- Unit_Price
- Revenue
- Discount_Percent

## 🔍 SQL Analysis Performed

The project covers the following SQL concepts:

- SELECT, WHERE and ORDER BY
- GROUP BY and HAVING
- Aggregate Functions (SUM, COUNT, AVG, MIN, MAX)
- Date Functions
- Subqueries
- Common Table Expressions (CTEs)
- CASE Statements
- Window Functions
- RANK()
- Running Total
- Revenue Contribution Analysis
- Top 5 Product Analysis

## 📈 Power BI Dashboard Features

The interactive dashboard includes:

- Total Revenue – ₹12,03,210
- Total Quantity – 179
- Total Orders – 36
- Product-wise Revenue Analysis
- Revenue by Region
- Monthly Revenue Trend
- Region Slicer
- City Slicer
- Category Slicer

## 💡 Key Insights

- Total sales revenue is ₹12,03,210.
- A total of 179 units were sold.
- The dataset contains 36 orders.
- Laptop generated the highest revenue among the listed products.
- The West region recorded the highest revenue among the four regions.
- Interactive slicers allow users to explore sales performance by region, city, and category.

## 🎯 Project Objectives

- Practice SQL querying and data analysis.
- Understand business performance through sales data.
- Identify top-performing products and regions.
- Analyze monthly sales trends.
- Build an interactive Power BI dashboard.
- Convert raw data into meaningful business insights.
